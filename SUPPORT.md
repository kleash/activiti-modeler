# Getting help

## Read first

- [Install guide](docs/user-guide/install.md): the downloads, opening an app that is not signed, Docker, and a table of common problems.
- [User guide](docs/README.md): modeling, the properties panel, running and testing, scenarios, DMN, the Camunda 7 import and a page for every lint rule.
- [Engine findings](docs/engine-findings.md): what Activiti 9.0.0 does that you might not expect, each with the test that shows it. Look there first when a process runs differently from what its model seems to say.
- [Integration guide](docs/integration-guide.md): running exported projects in your own Spring Boot application.

## Ask

- **Questions, ideas and "how do I ..."**: [GitHub Discussions](https://github.com/kleash/activiti-modeler/discussions).
- **A bug**: [open an issue](https://github.com/kleash/activiti-modeler/issues/new/choose) with the bug report form. The modeler version, how you run it, the Activiti version and the BPMN or DMN file (or the project zip from **File > Export project as zip**) make it possible to reproduce.
- **A feature**: the feature request form on the same page. Say what you want to do, and the Activiti behaviour it needs if you know it.
- **A vulnerability**: never in an issue or a discussion. Report it privately as [SECURITY.md](SECURITY.md) describes.

Answers come as time allows; there is no paid support.
